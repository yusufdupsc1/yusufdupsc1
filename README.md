## About

I'm a backend and full-stack engineer specializing in **Stripe integration and webhook reliability** — the part of a payments system that has to work correctly every single time, or a customer gets charged twice or not at all. I also work as a DevOps generalist: CI/CD, Linux server administration, and deployment infrastructure.

I run real production software for a school in Bangladesh — not a demo, not a tutorial project, an actual system real people use daily. I'm currently building **OpenSchoolOS**, a FastAPI + Next.js system for teachers to track individual student learning cases, and maintaining **clientflow-pro**, a SaaS payment dashboard built in PHP (linked below, pinned).

**Currently deepening:** Kubernetes, as the last major gap in an otherwise complete infrastructure-engineering foundation (Linux, networking, containers, CI/CD, Terraform).
